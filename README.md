# QUTy-CAB202

CAB202 – QUTy Embedded Systems Project

This project was developed for CAB202 (Microprocessors and Digital Systems) at QUT, using the QUTy microcontroller board.

It demonstrates low-level programming with C and Assembly, focusing on direct hardware interaction, real-time input/output, and understanding how software communicates with a microprocessor at a bare-metal level.

## Key Highlights

- C and Assembly language programming
- Direct interaction with QUTy hardware peripherals
- Real-time I/O handling
- Hands-on embedded systems experience
